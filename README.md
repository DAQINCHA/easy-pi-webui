# easy-pi-webui

给 [pi](https://pi.dev) 做的一个网页界面，面向不写代码、不看代码的小白 vibecoder：不用记命令、不用读代码，打开网页就能给 pi 派活、看进度、管理会话。底层用 pi 自己的 RPC 模式跑真实的 pi 会话。

零 npm 依赖：服务端只用 Node 内置模块，前端是原生 HTML/CSS/JS，没有构建步骤。

## 启动

前提：Node.js 22.19 或更新，并且已经装好、登录过 pi（终端里 `pi --version` 有输出）。

```bash
cd node-server/easy-pi-webui
npm start
```

然后打开 <http://127.0.0.1:30142>。macOS 下也可以直接双击 `启动 easy-pi-webui.command`（它会起服务并帮你打开网页）。

工作目录按下面的优先级决定，**每台电脑各自记住自己的选择**，配置写在 `~/.config/easy-pi-webui/settings.json`（不在 iCloud、不碰 `~/.pi`）：

1. 命令行 `--workspace /path`
2. 环境变量 `PI_WORKSPACE`
3. 这台电脑上次保存的选择
4. 都没有 → **首次使用**：网页会弹出「选择工作目录」，选好才允许发消息；此时不会启动任何 pi 子进程、不会发模型请求、不会恢复或新建会话。

显式参数 / 环境变量给的路径无效时会明确报错并进入「未选择」状态，不会悄悄换成别的目录；保存的路径失效、配置文件读不出来也一样。选择保存在本机，命令行 / 环境变量的覆盖只在当次生效，不改写配置文件。

启动后在左下角点「工作目录」也能随时切换，不重启服务就能换项目；页面主动切换会保存为新默认。系统目录选择框只在 macOS 可用，其他系统可以直接在弹窗里输入绝对路径。最近使用的 8 个目录记在浏览器本地，只作为快捷入口，不参与启动默认值。

## 能做什么

- 会话侧栏：按「今天 / 昨天 / 7 天内 / 更早」分组，能搜索、能开多个会话，切走的会话在后台继续跑
- 工作区切换：左下角目录卡片点「打开工作区」在 Finder 里选目录，或点最近目录；记住最近 8 个（悬停可删除记录），不重启服务就能换项目
- 消息编辑 / 重新生成：用户消息悬停可「编辑」（从那条消息之前分叉，原文放回输入框，改完再发），最后一条用户消息和最后一条回答还能「重新生成」；正在回复时按钮置灰，带图片的消息禁用并提示（分叉后图片会丢）
- 本轮改动摘要：每轮结束在回答下方居中出现一个「N 个文件已更改」胶囊，点开列出每个文件和所在目录；只讲文件改动，不显示增删行数、不统计命令数。只认 `edit` / `write` 的路径，用 `bash` 间接写文件统计不到，那一轮没记录到文件就不显示胶囊
- 完成通知：「更多」菜单里可开「完成时通知」（默认关），页面不在前台且本轮跑完时弹系统通知；主动停止、断线回放不弹
- 可安装（PWA）：支持的浏览器可以把界面「安装到桌面 / 手机主屏」，用独立窗口打开；断网时至少还能打开外壳（界面 + 样式 + 脚本），但聊天、会话、模型都必须联网才能用
- 自动命名：第一次对话结束后，让模型起一个短标题并存进会话（`PI_AUTO_TITLE=0` 可关闭）
- 会话置顶：活动会话悬停时，归档图标左边多一个图钉图标，点一下即置顶（再点取消）；置顶的会话收进侧栏顶部独立于时间分组的「已置顶」分组，归档会话会自动取消置顶
- 会话归档：活动会话悬停点右侧的归档图标即可归档；归档的会话收进侧栏底部「已归档」分组，点「…」可以取消归档或删除会话
- 流式回复：文字边生成边显示，代码块有语法高亮和复制按钮
- 思考过程：折叠显示，可展开
- 工具调用：命令、文件读取、编辑差异（红绿 diff）、写入内容都以卡片展示，可折叠，带耗时和成功/失败状态
- 模型与思考深度切换、上下文占用百分比、token 与费用统计
- 斜杠命令：`/skill:xxx`、prompt 模板、扩展命令，输入 `/` 就有候选
- 图片：粘贴、拖入或点按钮添加，随消息一起发给 pi
- 压缩上下文、重命名会话、停止当前任务（Esc）
- 深色 / 浅色 / 跟随系统三种外观，窄屏自动变成抽屉式侧栏

## 它是怎么跑起来的

浏览器 ←SSE← Node 服务 ←JSONL/stdin+stdout→ `pi --mode rpc` 子进程

- 每个会话对应一个 pi 子进程，会话文件仍然写在 `~/.pi/agent/sessions/`，和命令行里的 pi 完全共用
- 服务端把 pi 的事件原样转发给浏览器，浏览器负责拼出流式消息和工具卡片
- 15 分钟无活动、没有连接、也不在跑任务的子进程会被回收

用的是 pi 官方文档里的 [RPC 模式](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/rpc.md)，不是进程内 SDK——这样不用装 `@earendil-works/*` 依赖，也不会和已安装的 pi 版本打架。两者用的是同一套会话、模型和工具。

## 配置

| 环境变量 | 作用 | 默认 |
| --- | --- | --- |
| `PI_WORKSPACE` | pi 的工作目录（会话也按它分组）；仅当次生效，不改写本机配置 | 本机保存 / 首次选择 |
| `PORT` / `PI_WEBUI_PORT` | 监听端口 | `30142` |
| `HOST` | 监听地址 | `127.0.0.1` |
| `PI_BIN` | pi 可执行文件路径 | `pi` |
| `PI_SESSION_DIR` | pi 会话根目录 | `~/.pi/agent/sessions` |
| `PI_AUTO_TITLE` | 设为 `0` 关闭首次对话后的自动命名 | 开启 |
| `PI_TITLE_MODEL` | 生成标题用的模型（对应 `pi --model`） | pi 默认模型 |

也可以用命令行参数：`node server.js --workspace /path --port 30142 --host 127.0.0.1`。

## 停止与退出

- 前台 `npm start` / `node server.js`：按 `Ctrl + C`（SIGINT），或直接发 `SIGTERM` / `SIGHUP`，都会走同一套清理。
- 双击 `启动 easy-pi-webui.command`：关掉那个终端窗口、按 `Ctrl + C`、或终端断开导致的 HUP 都会触发清理；脚本只向自己记录的那个服务进程转发信号，不会按端口杀进程、不会误杀别的 pi 或 node。
- 退出时会停止接收新请求、关掉 SSE、回收所有 pi 子进程和自动命名子进程（先 TERM，必要时 KILL，有超时兜底），确认退出后才结束。重复发信号不会重复清理。
- **不会**因为关闭标签页、刷新页面就杀掉正在跑的任务；断页继续和 15 分钟闲置回收保持原样。
- 限制：`SIGKILL`、系统崩溃、断电无法捕获；没有设计进程组，因此不保证 pi 自己派生的任意孙进程全部被回收；也不会去碰你独立开的命令行 pi。

## 注意

- 默认只监听本机。改成 `0.0.0.0` 等于把「能执行命令的 agent」暴露到局域网，而且这个界面没有登录功能。
- 侧栏只列当前工作目录的会话；用左下角的目录卡片切换，切走的目录里正在跑的会话会留在后台。
- 系统目录选择框目前只在 macOS 可用；Windows / Linux 可以在选目录弹窗里直接输入路径。
- 保存配置文件失败时会明确提示「目录已切换但没记住」，旧配置不会被覆盖或损坏；重启后需要重新选择。
- 还没做：项目文件浏览、上传文件、Git 面板、导出 HTML。

## PWA / 离线外壳

Service Worker 只在**安全上下文**里工作：`http://127.0.0.1:30142`、`http://localhost:30142` 或 HTTPS 都算；用局域网 IP 走普通 HTTP（例如 `http://192.168.1.10:30142`）不行，浏览器会直接拒绝注册，页面本身照常能用，只是不能安装、也没有离线外壳。

- **安装**：用 Chrome / Edge 打开页面后，地址栏右侧会出现安装图标；也可以在「更多」菜单里点「安装到桌面」（浏览器给出安装事件时才显示，已经是独立窗口时不显示）。iPhone / iPad 用 Safari 的「分享 → 添加到主屏幕」。
- **断网**：外壳用 network-first 缓存，断网刷新还能看到界面；但 `/api/*` 一律不缓存、不伪造，所以这时会话列表和发消息都会报「后端未连接」之类的错误，这是正常的。
- **更新**：静态资源同样是 network-first，改完前端刷新就是新代码，不会卡在旧缓存；SW 自己 `skipWaiting()` + `clientsClaim()`，新版本不用关光所有标签页。
- Service Worker 注册失败（比如浏览器禁用、非安全上下文）不影响页面其他功能，只是不能安装、断网打不开、通知回退到普通 `new Notification`。
